Privacy Policy

Flag Race League Tools · last updated 23 October 2026

Flag Race League Tools is a set of personal command-line tools run by the operator of the channel and Facebook Page Flag Race League (@flagraceleague). The tools run on the operator's own computer. They are not a hosted service and have no users other than their operator. This policy covers both parts:

  • Flag Race Uploader: publishes finished videos to the operator's own YouTube channel through the YouTube Data API v3.
  • Flag Race League Tools (Meta app ID 1119894460490991): publishes Reels, videos, photos and text posts to the operator's own Facebook Page through the Facebook Graph API, and posts the Page's own comments under them.

YouTube: what data the application accesses

When the operator signs in with Google, the uploader requests three permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos and set thumbnails on the channel belonging to the account that signed in.
  • https://www.googleapis.com/auth/youtube.readonly: to read that channel's name, its list of uploads, their privacy status and public statistics (views, likes, comment counts), and the comments on the channel's own videos.
  • https://www.googleapis.com/auth/youtube.force-ssl: to change the scheduled publishing time or privacy of the channel's own uploads, add them to the channel's own playlists, post and reply to comments as the channel, and update the channel's description and keywords, only when the operator runs the matching command.

No other Google data is requested or accessible. The application does not read Gmail, Drive, Contacts, Calendar, location, or any other Google service.

Facebook: what data the application accesses

The Meta app is used only with the operator's own Facebook Page. It holds a Page access token for that one Page and requests these permissions:

  • pages_show_list, public_profile: to identify which Page the operator manages and confirm the right Page is connected.
  • pages_manage_posts, publish_video: to publish and schedule Reels, videos, photos and text posts on the Page, and to delete the Page's own posts when the operator asks.
  • pages_read_engagement, pages_read_user_content: to read the Page's own posts, their publishing status and view counts, so the same video is not published twice.
  • pages_manage_engagement: to post comments as the Page under the Page's own posts, for example the link to the same video on YouTube.

The application does not read the Page's inbox, does not access the operator's personal profile beyond its public name, does not access friends, groups, ads or any other Page, and does not read any data about people who view, like, follow, comment on or share the Page's posts.

What data is stored, and where

Everything the application stores is written to files on the operator's own computer. Nothing is transmitted to the developer, and there is no server, database, or hosted backend of any kind.

  • Credentials: the Google OAuth refresh token and client credentials, and the Meta app ID, app secret and Page access token, each in a local file so the operator does not have to sign in again on every run.
  • Publishing record: for each video, the YouTube video ID and the Facebook post and video IDs, the time of publishing, whether its first comment has been posted, and a count of API calls used today. This exists so the same video is not published twice and so API limits are respected.
  • Video notes: the title, description, tags and publishing time written for each video, kept next to the video on the operator's disk.
  • Video cache: copies of the operator's own public YouTube videos downloaded so they can be published to the Page, kept in a local folder.

Video files and their text are read from the operator's own disk and sent directly to YouTube or Facebook. They are not copied anywhere else.

Who the data is shared with

Nobody. The only network connections the application makes are to Google's API endpoints (accounts.google.com, oauth2.googleapis.com, googleapis.com) and to Meta's Graph API (graph.facebook.com and its upload hosts), in order to carry out the operator's instructions. There are no analytics, no telemetry, no advertising, no third-party services, and no sale or transfer of data to anyone.

Flag Race League Tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of data received from Meta's platform adheres to the Meta Platform Terms and Developer Policies.

How long data is kept

Credentials, the publishing record, video notes and the video cache stay on the operator's computer until deleted. They are removed by deleting the application's local files, or by uninstalling the application entirely.

Deleting your data

The only person whose data the application holds is its operator. To delete it, revoke Google access at myaccount.google.com/permissions, remove the app Flag Race League Tools from your Facebook account's Business Integrations settings, and delete the application's local files. Both revocations make the stored tokens useless immediately. Anyone else who believes the application holds data about them can raise a request at github.com/namphuong369; it will be answered, and any such data deleted, within 30 days.

Children

The application is a developer tool and is not directed at children.
