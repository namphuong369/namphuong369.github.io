Privacy Policy

Flag Race Uploader · last updated 26 September 2026

Flag Race Uploader is a personal command-line tool that uploads video files to the YouTube channel of the person who runs it. It runs on that person's own computer. It is not a hosted service and has no users other than its operator.

What data the application accesses

When the operator signs in with Google, Flag Race Uploader requests three permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos and set thumbnails on the channel belonging to the account that signed in.
  • https://www.googleapis.com/auth/youtube.readonly: to read that channel's name, its list of uploads, their privacy status and public statistics (views, likes, comment counts), and the comments on the channel's own videos.
  • https://www.googleapis.com/auth/youtube.force-ssl: to change the scheduled publishing time or privacy of the channel's own uploads, add them to the channel's own playlists, post and reply to comments as the channel, and update the channel's description and keywords, only when the operator runs the matching command.

No other Google data is requested or accessible. The application does not read Gmail, Drive, Contacts, Calendar, location, or any other Google service.

What data is stored, and where

Everything the application stores is written to files on the operator's own computer. Nothing is transmitted to the developer, and there is no server, database, or hosted backend of any kind.

  • OAuth refresh token: stored in a local file so the operator does not have to sign in again on every run.
  • OAuth client credentials: the client ID and secret issued by Google Cloud, stored in a local file.
  • Upload record: for each video the application has uploaded, the YouTube video ID, the time of upload, whether its first comment has been posted, the IDs of the channel's playlists it has used, and a count of API quota used today. This exists so the same video is not uploaded twice and so the daily API quota is respected.
  • Video notes: the title, description, tags and publishing time written for each video, kept next to the video on the operator's disk.

Video files and their text are read from the operator's own disk and sent directly to YouTube. They are not copied anywhere else.

Who the data is shared with

Nobody. The only network connections the application makes are to Google's own API endpoints (accounts.google.com, oauth2.googleapis.com and googleapis.com) in order to carry out the operator's instructions. There are no analytics, no telemetry, no advertising, no third-party services, and no sale or transfer of data to anyone.

Flag Race Uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

How long data is kept

The refresh token, upload record and video notes stay on the operator's computer until deleted. They are removed by deleting the application's local files, or by uninstalling the application entirely.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Revoking it makes the stored refresh token useless immediately. Deleting the local token file has the same practical effect on the operator's machine.

Children

The application is a developer tool and is not directed at children.
