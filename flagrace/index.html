Flag Race Uploader

A personal command-line tool that publishes finished Shorts to its operator's own YouTube channel, Flag Race League.

What it does

Flag Race Uploader is a small script run from a terminal on the operator's computer. The operator drops finished video files into a local folder. The tool reads each file and the notes kept alongside it, writes the title, description and tags, picks the next free publishing slot, and uploads the video to the operator's own YouTube channel through the YouTube Data API v3 as a scheduled video.

Who it is for

One person: the operator who installs it and connects their own channel. It is not a hosted service, it has no user accounts, and it does not act on behalf of anyone other than the Google account that authorised it.

What it asks permission for

  • youtube.upload: to upload videos and set their thumbnails on the channel of the account that signed in. This is the main purpose of the tool.
  • youtube.readonly: to read back the channel's name, its list of uploads and their public statistics, so the operator can confirm the right channel is connected and avoid uploading the same video twice.
  • youtube.force-ssl: to manage the operator's own uploads after they are created: change the scheduled publishing time, add videos to the channel's playlists, post the channel's own first comment under a new video, reply to comments when the operator types a reply, and update the channel description and keywords when the operator asks for it.

It does not request, and cannot use, any other Google data.

Where it runs

Entirely on the operator's own computer. There is no server, no database and no third party in the path. The only network connections it makes are to Google's own API endpoints.
