Night Drive Remix Tools

Personal command-line tools that publish finished music videos to their operator's own YouTube channel, Night Drive Remix (@nightdriveremix).

What it does

The tools are small scripts run from a terminal on the operator's computer. The operator drops finished video files into a local folder together with a short note (song name, timeline). The tools read each file and its note, write the title, description, tags and the channel's own first comment, pick the next free publishing slot, and publish the video as a scheduled video on the operator's own YouTube channel through the YouTube Data API v3. Other commands add the video to the channel's playlists, set the thumbnail, update the channel's banner, watermark, description and keywords, list the channel's own statistics, and post or reply to comments as the channel.

Who it is for

One person: the operator who installs it and connects their own channel. It is not a hosted service, it has no user accounts, and it does not act on behalf of anyone other than the Google account that authorised it.

What it asks permission for

  • youtube.upload: to upload videos, set their thumbnails, and upload the channel banner and watermark on the channel of the account that signed in.
  • youtube.readonly: to read back the channel's name, its list of uploads and their public statistics, so the operator can confirm the right channel is connected and avoid uploading the same video twice.
  • youtube.force-ssl: to manage the operator's own uploads after they are created: change the scheduled publishing time, add videos to the channel's playlists, post the channel's own first comment, reply to comments, and update the channel description, keywords, banner and watermark when the operator asks for it.

It does not request, and cannot use, any other Google data.

Where it runs

Entirely on the operator's own computer. There is no server, no database and no third-party service in the path. Credentials and the publishing record are plain local files. Network traffic goes only to Google's own API endpoints.

Source

The scripts live in a private repository of the operator's GitHub account, github.com/namphuong369.
