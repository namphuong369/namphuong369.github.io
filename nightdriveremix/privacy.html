Privacy Policy

Night Drive Remix Tools · last updated 30 October 2026

Night Drive Remix Tools (the OAuth application Night Drive Remix Uploader) is a set of personal command-line tools run by the operator of the YouTube channel Night Drive Remix (@nightdriveremix). The tools run on the operator's own computer, publish finished music videos to that one channel through the YouTube Data API v3, and manage the channel's own playlists, comments and branding. They are not a hosted service and have no users other than their operator.

What data the application accesses

When the operator signs in with Google, the application requests three permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos, set thumbnails, and upload the channel banner and watermark on the channel belonging to the account that signed in.
  • https://www.googleapis.com/auth/youtube.readonly: to read that channel's name, its list of uploads, their privacy status and public statistics (views, likes, comment counts), and the comments on the channel's own videos.
  • https://www.googleapis.com/auth/youtube.force-ssl: to change the scheduled publishing time or privacy of the channel's own uploads, add them to the channel's own playlists, post and reply to comments as the channel, and update the channel's description, keywords, banner and watermark, only when the operator runs the matching command.

The application reads only the channel of the signed-in account and public data of videos the operator chooses to comment on. It does not access Google contacts, Gmail, Drive, or any other Google service.

How the data is used

  • The channel name and ID are shown to the operator to confirm the right channel is connected, and stored so uploads go to that channel.
  • The list of uploads and their titles are compared with the videos waiting locally so the same video is never published twice.
  • Public statistics are shown to the operator in a terminal table to judge which videos performed well. They are not shared with anyone.
  • Comments on the channel's own videos are listed so the operator can reply. Replies are written by the operator; the tool only sends them.
  • For the optional "comment on related videos" command, the title, description and a few public comments of a public video found through YouTube search are sent to an AI model operated by Anthropic, which drafts one comment. No private data and no data about the video's viewers are involved.

What is stored, and where

  • Credentials: the Google OAuth client ID and secret, and the refresh token issued to the operator, each in a local file readable only by the operator's user account.
  • Publishing record: for each video, the YouTube video ID, the time it was uploaded, its privacy status and which playlists it was added to, plus a daily counter of API quota used. This prevents duplicate uploads.
  • Video notes: the title, description, tags and comment text written for each video, kept next to the publishing record.

All of this stays on the operator's computer. It is not copied anywhere else. The application does not use cookies, analytics or advertising of any kind.

Sharing

The application sends data only to Google's YouTube APIs (googleapis.com) and, for the optional comment-drafting command only, to Anthropic's API with the public text described above. It does not sell, rent or otherwise share data with anyone.

Night Drive Remix Tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also complies with the YouTube Terms of Service; by using it, the operator also agrees to be bound by those terms and by the Google Privacy Policy.

Retention and deletion

Credentials, the publishing record and video notes stay on the operator's computer until deleted. To revoke the application's access, remove Night Drive Remix Uploader at myaccount.google.com/permissions; the stored refresh token then stops working. Deleting the local files removes everything the application holds.

Changes and contact
