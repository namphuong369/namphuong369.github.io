Privacy Policy

True Crime Doodles Tools · last updated 27 October 2026

True Crime Doodles Tools is a set of personal command-line tools run by the operator of the YouTube channel True Crime Doodles (@truecrimedoodles). The tools run on the operator's own computer. They are not a hosted service and have no users other than their operator. They publish finished videos to that one channel through the YouTube Data API v3, read the channel's own analytics through the YouTube Analytics API, and help the operator answer comments on the channel's own videos.

What data the application accesses

When the operator signs in with Google, the application requests these permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos, set their thumbnails and attach subtitle files (captions) on the channel belonging to the account that signed in.
  • https://www.googleapis.com/auth/youtube and https://www.googleapis.com/auth/youtube.force-ssl: to manage that same channel after upload, only when the operator runs the matching command: change a video's title, description, tags, scheduled time or privacy; create and fill the channel's own playlists; post the channel's own first comment and reply to comments on the channel's own videos; review comments held for moderation; update the channel's description, keywords, banner, watermark and home-page sections.
  • https://www.googleapis.com/auth/yt-analytics.readonly and https://www.googleapis.com/auth/yt-analytics-monetary.readonly: to read the channel's own YouTube Analytics reports (views, watch time, audience retention, countries, traffic sources, search terms and, once the channel is monetised, estimated revenue) so the operator can decide which case to draw next and when to publish.

No other Google data is requested or accessible. The application does not read Gmail, Drive, Contacts, Calendar, location, or any other Google service, and it does not access any channel other than the one that signed in.

Comments on the channel's videos

When the operator runs the comment command, the application fetches new public comments on the channel's own videos: the comment text, the commenter's public display name and channel ID as YouTube shows them to the channel, and timestamps. Nothing else about the commenter is requested.

To help the operator answer, the text of a comment may be sent to Claude, an AI model operated by Anthropic, which drafts a short reply in the channel's voice using only the facts the operator has already verified for that case. Anthropic's processing of that text is governed by Anthropic's privacy policy. The text is sent only for drafting a reply and is not used for any other purpose. Comments are never stored beyond the local log described below.

What data is stored, and where

Everything the application stores is written to files on the operator's own computer. Nothing is transmitted to the developer, and there is no server, database, or hosted backend of any kind.

  • Credentials: the Google OAuth refresh token and client credentials, in a local file so the operator does not have to sign in again on every run.
  • Publishing record: for each video, its YouTube video ID, the time of publishing, the playlists it was added to, whether its first comment has been posted, and a count of API calls used today, so the same video is not published twice and API limits are respected.
  • Video notes: the title, description, chapters, sources, tags, subtitle file and publishing time written for each video, kept next to the video on the operator's disk.
  • Analytics exports: the channel's own analytics reports, downloaded as local files for the operator to read.
  • Comment record: the IDs of comments already answered, the time of the last check, and a local log of the comments read and the replies sent, so the same comment is not answered twice and the operator can review what was said.

Video, thumbnail and subtitle files are read from the operator's own disk and sent directly to YouTube. They are not copied anywhere else.

Who the data is shared with

The only network connections the application makes are to Google's API endpoints (accounts.google.com, oauth2.googleapis.com, googleapis.com) and, for drafting replies to comments only, to Anthropic's Claude. Each receives only what is needed to carry out the operator's instruction. There are no analytics, no telemetry, no advertising, no other third-party services, and no sale or transfer of data to anyone.

True Crime Doodles Tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services and is subject to the YouTube Terms of Service; see also the Google Privacy Policy.

How long data is kept

Credentials, the publishing record, video notes and analytics exports stay on the operator's computer until deleted. The local comment log is kept for no longer than 90 days. All of it is removed by deleting the application's local files.

Deleting your data

If you are the operator: revoke the application's access at myaccount.google.com/permissions and delete the application's local files. Revocation makes the stored token useless immediately.

If you have commented on one of the channel's videos and want the local copy of your comment and any reply to be deleted, raise a request at github.com/namphuong369. The local record is deleted within 30 days of the request and you will be told when it is done. Deleting the comment on YouTube itself is done through YouTube and is governed by Google's own policies.

Children

The application is a developer tool and is not directed at children. The channel it serves is marked as not made for kids.

Changes

If this policy changes, the revised version is published on this page with a new date at the top.

Contact
