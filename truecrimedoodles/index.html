True Crime Doodles Tools

Personal command-line tools that publish hand-drawn true crime videos to their operator's own YouTube channel, True Crime Doodles (@truecrimedoodles), and help the operator look after that channel.

What it does

The tools are small scripts run from a terminal on the operator's computer. Each episode is researched, drawn and narrated on that computer first. The tools then read the finished video and the notes kept alongside it, write the title, description, chapters, sources and tags, pick the publishing time, upload the video as a scheduled video through the YouTube Data API v3, attach the thumbnail and the subtitle file, add the video to the channel's playlists and post the channel's own first comment. Separate commands read the channel's YouTube Analytics reports, review new comments on the channel's own videos, and draft short replies with an AI model for the operator to send as the channel.

Who it is for

One person: the operator who installs it and connects their own channel. It is not a hosted service, it has no user accounts, and it does not act on behalf of anyone other than the Google account that authorised it.

What it asks permission for

  • https://www.googleapis.com/auth/youtube.upload: to upload videos, set their thumbnails and attach subtitle files (captions) on the channel belonging to the account that signed in.
  • https://www.googleapis.com/auth/youtube and https://www.googleapis.com/auth/youtube.force-ssl: to manage that same channel after upload, only when the operator runs the matching command: change a video's title, description, tags, scheduled time or privacy; create and fill the channel's own playlists; post the channel's own first comment and reply to comments on the channel's own videos; review comments held for moderation; update the channel's description, keywords, banner, watermark and home-page sections.
  • https://www.googleapis.com/auth/yt-analytics.readonly and https://www.googleapis.com/auth/yt-analytics-monetary.readonly: to read the channel's own YouTube Analytics reports (views, watch time, audience retention, countries, traffic sources, search terms and, once the channel is monetised, estimated revenue) so the operator can decide which case to draw next and when to publish.

It does not request, and cannot use, any other Google data. It does not read Gmail, Drive, Contacts, Calendar, location, or any other Google service.

Where it runs

Entirely on the operator's own computer. There is no server, no database and no third-party service in the path, except that the text of a comment the operator chooses to answer is sent to an AI model (Claude, by Anthropic) to draft the reply. The only other network connections it makes are to Google's own API endpoints.
