Privacy Policy

Sep Khong Doc Dau Tools · last updated 23 October 2026

Sep Khong Doc Dau Tools is a set of personal command-line tools run by the operator of the channel and Facebook Page Sếp Không Đọc Đâu (@sepkhongdocdau). The tools run on the operator's own computer. They are not a hosted service and have no users other than their operator. This policy covers both parts:

  • Sep Khong Doc Dau Uploader: publishes finished videos to the operator's own YouTube channel through the YouTube Data API v3.
  • Sep Khong Doc Dau Tools (Meta app ID 1114435534527619): publishes Reels, videos, photos and text posts to the operator's own Facebook Page through the Facebook Graph API, and reads and answers messages sent to that Page.

YouTube: what data the application accesses

When the operator signs in with Google, the uploader requests three permissions:

  • https://www.googleapis.com/auth/youtube.upload: to upload videos and set thumbnails on the channel belonging to the account that signed in.
  • https://www.googleapis.com/auth/youtube.readonly: to read that channel's name, its list of uploads, their privacy status and public statistics (views, likes, comment counts), and the comments on the channel's own videos.
  • https://www.googleapis.com/auth/youtube.force-ssl: to change the scheduled publishing time or privacy of the channel's own uploads, add them to the channel's own playlists, post and reply to comments as the channel, and update the channel's description and keywords, only when the operator runs the matching command.

No other Google data is requested or accessible. The application does not read Gmail, Drive, Contacts, Calendar, location, or any other Google service.

Facebook: what data the application accesses

The Meta app is used only with the operator's own Facebook Page. It holds a Page access token for that one Page and requests these permissions:

  • pages_show_list, public_profile: to identify which Page the operator manages and confirm the right Page is connected.
  • pages_manage_posts, publish_video: to publish and schedule Reels, videos, photos and text posts on the Page, and to delete the Page's own posts when the operator asks.
  • pages_read_engagement, pages_read_user_content: to read the Page's own posts, their publishing status, view counts and the list of scheduled posts, so the same video is not published twice and two posts are not scheduled for the same slot.
  • pages_manage_engagement: to post comments as the Page under the Page's own posts.
  • pages_messaging, pages_manage_metadata: to read the conversations in the Page's inbox and to send replies as the Page.

The application does not access the operator's personal profile beyond its public name, does not access friends, groups, ads or any other Page, and does not read any data about people who merely view, like, follow, comment on or share the Page's posts.

Messages sent to the Page

When someone writes to the Page's inbox, the tool fetches that conversation: the text of the messages, the sender's name as Facebook shows it to the Page, the Page-scoped sender ID, and timestamps. Nothing else about the sender is requested.

To help the operator answer, the text of the conversation is sent to Claude, an AI model operated by Anthropic, which drafts a short reply in the Page's voice. The draft is then sent to the sender as the Page. Anthropic's processing of that text is governed by Anthropic's privacy policy. The text is sent only for drafting a reply and is not used by the operator for any other purpose.

What data is stored, and where

Everything the application stores is written to files on the operator's own computer. Nothing is transmitted to the developer, and there is no server, database, or hosted backend of any kind.

  • Credentials: the Google OAuth refresh token and client credentials, and the Meta app ID, app secret and Page access token, each in a local file so the operator does not have to sign in again on every run.
  • Publishing record: for each video, the YouTube video ID and the Facebook post and video IDs, the time of publishing, whether its first comment has been posted, and a count of API calls used today. This exists so the same video is not published twice and so API limits are respected.
  • Video notes: the title, description, tags and publishing time written for each video, kept next to the video on the operator's disk.
  • Message record: the conversation IDs already answered, the time of the last check, and a local log of received messages and the replies sent, so the same message is not answered twice and the operator can review what was said.

Video files and their text are read from the operator's own disk and sent directly to YouTube or Facebook. They are not copied anywhere else.

Who the data is shared with

The only network connections the application makes are to Google's API endpoints (accounts.google.com, oauth2.googleapis.com, googleapis.com), to Meta's Graph API (graph.facebook.com and its upload hosts), and, for drafting replies to Page messages only, to Anthropic's Claude. Each of these receives only what is needed to carry out the operator's instruction. There are no analytics, no telemetry, no advertising, no other third-party services, and no sale or transfer of data to anyone.

Sep Khong Doc Dau Tools' use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of data received from Meta's platform adheres to the Meta Platform Terms and Developer Policies.

How long data is kept

Credentials, the publishing record, video notes and the message record stay on the operator's computer until deleted. The local message log is kept for no longer than 90 days. All of it is removed by deleting the application's local files, or by uninstalling the application entirely.

Deleting your data

If you are the operator: revoke Google access at myaccount.google.com/permissions, remove the app Sep Khong Doc Dau Tools from your Facebook account's Business Integrations settings, and delete the application's local files. Both revocations make the stored tokens useless immediately.

If you have sent a message to the Page and want the local copy of that conversation and any reply to be deleted, send the Page a message saying so, or raise a request at github.com/namphuong369. The local record of your conversation is deleted within 30 days of the request and you will be told when it is done. Deleting the conversation on Facebook itself is done through Facebook or Messenger and is governed by Meta's own policies.

Children

The application is a developer tool and is not directed at children.
