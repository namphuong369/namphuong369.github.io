FightShort

A personal command-line tool for uploading finished video files to its operator's own YouTube channel.

What it does

FightShort is a small script run from a terminal. It takes a video file that has already been rendered on the operator's computer, reads the title, description and tags from a text file kept alongside it, and uploads the result to the operator's own YouTube channel through the YouTube Data API v3.

Who it is for

One person: the operator who installs it and connects their own channel. It is not a hosted service, it has no user accounts, and it does not act on behalf of anyone other than the Google account that authorised it.

What it asks permission for

  • youtube.upload — to create videos on the channel of the account that signed in. This is the whole purpose of the tool.
  • youtube.readonly — to read back the channel's name, so the operator can confirm the right account is connected before anything is uploaded.

It does not request, and cannot use, any other Google data.

Where it runs

Entirely on the operator's own computer. There is no server, no database and no third party in the path — the only network connections it makes are to Google's own API endpoints.
